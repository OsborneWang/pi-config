# Global Agent Instructions

## File References
- In user-facing responses, show the full absolute path for every local file reference. A clickable Markdown link may be included, but its hidden link target does not satisfy this requirement; also print the absolute path visibly in parentheses.
- Example: [Workspace.vue](/WorkSpace/project/src/Workspace.vue:42) (`/WorkSpace/project/src/Workspace.vue:42`).
- Do not refer to local files using only a basename or relative path.
